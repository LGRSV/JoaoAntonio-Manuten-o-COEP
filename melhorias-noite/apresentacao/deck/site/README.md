# ARGOS Manutenção · apresentação

Apresentação de 10 minutos do ARGOS em 23 slides animados (estilo PowerPoint), com os prints do site no computador.
Abrir: `index.html` desta pasta no navegador (ou o Artifact da apresentação).

## Mudar os textos

Todos os textos (capa, títulos, blocos, tempos, tópicos, frases das notas, marca, endereço do quadro e rótulos) ficam em
**`textos.js`**. Dois jeitos de mudar:

1. **Na própria apresentação:** botão **Editar textos** (ou tecla **E**). Clique num texto e escreva; Enter num tópico cria
   outro e tópico vazio some ao salvar; Ctrl+B e Ctrl+I deixam em negrito e itálico. **Salvar** (ou Ctrl+S) guarda neste
   navegador e baixa um `textos.js` novo: troque o desta pasta para valer em qualquer lugar. **Descartar** desfaz;
   **Voltar ao texto original** volta ao `textos.js` da pasta.
   No Artifact, Salvar vale na hora para todos que abrem a apresentação.
2. **No arquivo:** edite `textos.js` aqui no GitHub (mantenha as aspas e as vírgulas).

`gera_deck.py` (pasta acima) refaz `index.html` e as imagens sem mexer no `textos.js`; `--refaz-textos` volta os textos ao
roteiro `../revisao/README.md` (perde o que foi editado).

| Tecla | Ação |
|---|---|
| → · espaço · clique na direita | próximo slide |
| ← · clique na esquerda | slide anterior |
| F | tela cheia |
| G | todos os slides |
| N | notas (bloco, tempo e a frase de cada slide) |
| P | reproduzir sozinho (11 s por slide) |
| E | editar textos |

No celular: deslize para os lados. Link direto para um slide: `#s5`. Prints de 15/10/2026; Crítica de jan a ago/2026.
