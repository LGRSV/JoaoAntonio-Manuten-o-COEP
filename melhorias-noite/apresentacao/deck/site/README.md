# ARGOS Manutenção · apresentação

Apresentação de 10 minutos do ARGOS Manutenção em 23 slides animados, no formato de um PowerPoint, com os prints do site no computador.

Abrir: `index.html` desta pasta no navegador (ou o Artifact da apresentação).

| Tecla | Ação |
|---|---|
| → · espaço · clique na direita | próximo slide |
| ← · clique na esquerda | slide anterior |
| F | tela cheia |
| G | todos os slides |
| N | notas (bloco, tempo e a frase de cada bloco) |
| P | reproduzir sozinho (11 s por slide) |

No celular: deslize para os lados. Link direto para um slide: `#s5`.

Site de demonstração: https://lgrsv.github.io/vera-vegeta-o-back/teste/
